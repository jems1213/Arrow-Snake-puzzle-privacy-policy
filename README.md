# Arrow Snake Puzzle — Privacy Policy

The privacy policy for the **Arrow Snake Puzzle** Android game
(`com.snackpuzzle.snack_puzzle_game`), published as a page for the Google Play
listing's required privacy policy URL.

**Live page:** https://jems1213.github.io/Arrow-Snake-puzzle-privacy-policy/

The policy itself is [`index.html`](index.html). A Markdown copy of the same
text is in [`PRIVACY.md`](PRIVACY.md) for anyone reading it here on GitHub.

## Enabling the page

GitHub Pages has to be switched on once, by hand:

**Settings → Pages → Build and deployment → Source: Deploy from a branch →
Branch: `main` / `/ (root)` → Save**

The URL goes live a minute or so later. Paste it into
**Play Console → App content → Privacy policy**.

## Keeping it accurate

A privacy policy has to match what the app actually does. Update this page in
the same change as the app whenever any of these change:

- a new SDK is added (analytics, crash reporting, a second ad network)
- an ad format other than rewarded video is introduced
- anything is sent to a server, or an account system is added
- the contact address changes

Bump the "Last updated" date in `index.html` and `PRIVACY.md` when you do.
